# Tetris×2048

A hybrid puzzle game combining Tetris falling-block mechanics with 2048 merge logic, built with Flutter and Flame.

## Gameplay

Blocks fall and merge like 2048, but the board fills and clears like Tetris. Reaching 1,000,000 on a block "breaks" the meter and triggers a random season mode. Ten season modes (Bomb, Ice, Gravity, Chaos, Mystery, Dark, Volcano, Evolution, Electric, Prison) change the rules mid-run, each with its own visual theme and mechanic twist.

## Features

- 6×12 board with season-based mechanic variations
- 53 achievements across 6 categories
- Daily quest system (5 quest types, 6 slots/day)
- Block skin customization — replace special block visuals with your own gallery images
- Profile system with XP/level progression
- 15-language localization
- Life system with rewarded-ad and premium unlock paths
